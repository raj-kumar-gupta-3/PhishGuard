# 🛡️ PhishGuard

A beginner-friendly Python project that analyzes URLs for common phishing indicators.

## Features

- HTTPS check
- URL length check
- IP address detection
- Suspicious keyword detection
- @ symbol detection
- Basic risk scoring

## Technologies

- Python
- Regular Expressions
- URL Parsing

## Purpose

This project was created to practice Python programming and learn basic web security concepts.

## Disclaimer

This is an educational URL analyzer. It does not guarantee that a URL is safe or malicious.
